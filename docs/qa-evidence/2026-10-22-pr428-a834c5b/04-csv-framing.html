Tombstone

Finds rules that point at things that no longer exist: plugins that were uninstalled, roles that were deleted, users that are gone. Most of it is harmless clutter and only shows here. The one case that is sent as an alert is a plugin that comes back while its old Allow rule is still in place. Report only — it never deletes, edits or disables anything. Checks run on admin page loads and plugin activation, not on cron. Off by default.
