Doppelganger

Remembers this site's identity (address, environment, table prefix and a hashed database identity) and reports when the site no longer matches it, which is what a database cloned to staging or a new host looks like. Suggestion only — it never changes a webhook, email, budget or schedule. Alerts show here and as an admin notice; email and webhook delivery is a separate opt-in. Checks run on admin page loads, not on cron. Off by default.
