Deputy

When a pending AI access request waits longer than the SLA, notify a designated deputy. The site owner stays the primary approver. Deputy links approve or deny that one request only. Off by default.

Enable deputy

WordPress user ID of the backup approver. Takes precedence over role.

Used when no user ID is set. Any user with this role may use the signed link. Administrator is ignored.

Default 48. The deputy is notified only after a pending request is this old.

Optional. After this many days a pending request is denied and the requester can ask again. 0 keeps requests open.

Deputy is off. The site owner remains the only approver of AI access requests.
